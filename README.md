# 💫 About Me:
I'm a Computer Science graduate student at George Mason University, currently building full-stack and AI-integrated systems — right now that's TaskFlow, a production task management platform (FastAPI, PostgreSQL, Redis, React), and a job application automation pipeline that turns unstructured postings into structured data using n8n and the Gemini API. I'm especially interested in collaborating on AI-integrated backend systems — RAG pipelines, agentic workflows, and anything that combines LLMs with real production infrastructure, which is the space I worked in earlier this year building a GPT-4/LangChain-based RAG service. I'm currently deepening my understanding of distributed systems and exploring Go. Feel free to ask me about full-stack development, LLM/RAG integration, or my graduate research evaluating LLM behavior under degraded network conditions. Fun fact: my team took 1st place at the Challenge-X Hackathon (Internet2 Challenge, GMU), building a working cloud platform in under 24 hours.
